# Customer Behavior Data Analysis

## Project Overview

This project performs an end-to-end analysis of customer shopping behavior using Python, SQL, and Power BI. The objective is to clean and analyze customer purchase data, identify meaningful trends, and present the findings through an interactive dashboard.

## Objectives

* Analyze customer shopping behavior and purchasing patterns.
* Perform data cleaning and exploratory data analysis using Python.
* Use SQL to answer business-related questions.
* Build an interactive Power BI dashboard to visualize key insights.

## Technologies Used

* **Python:** Pandas, NumPy, Matplotlib
* **SQL:** Data querying and analysis
* **Power BI:** Interactive dashboard and visualizations
* **Jupyter Notebook:** Data analysis and documentation

## Project Files

* `Customer_Shopping_Behavior_Analysis.ipynb` – Python data analysis notebook.
* `customer_shopping_behavior.csv` – Dataset used for the analysis.
* `customer_behavior_dashboard.pbix` – Power BI dashboard.
* `Customer-Shopping-Behavior-Analysis.pptx` – Project presentation.
* `Business Problem Document.pdf` – Business problem statement.
* `Customer Shopping Behavior Analysis.pdf` – Project report.
* `requirements.txt` – Python dependencies.

## Analysis Performed

* Data cleaning and preprocessing.
* Exploratory Data Analysis (EDA).
* Customer purchasing pattern analysis.
* Category and demographic analysis.
* Business insights derived from the dataset.

## Key Insights

* Identified customer purchasing trends across different product categories.
* Analyzed spending behavior based on customer demographics.
* Highlighted important metrics using an interactive Power BI dashboard.

## How to Run the Project

1. Clone the repository.
2. Install the required Python libraries:

```bash
pip install -r requirements.txt
```

3. Open `Customer_Shopping_Behavior_Analysis.ipynb` in Jupyter Notebook.
4. Open `customer_behavior_dashboard.pbix` using Power BI Desktop to explore the dashboard.

## Dashboard

The Power BI dashboard provides an interactive view of customer shopping behavior, including key performance indicators, category-wise analysis, and customer demographic insights.
